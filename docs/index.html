Fulfulde Keyboard

Le clavier pulaar pour Windows · Taro Learning

Choisissez FUL avec Win + Espace : les touches donnent les lettres pulaar (v → ɓ, z → ɗ, q → ŋ, x → ƴ, ^ ou [ → ñ), une bulle propose des mots pulaar au-dessus du curseur (Tab pour choisir), et les fautes sont corrigées à l'espace. Avec Français ou Anglais, votre clavier ne change pas. Tout reste sur votre ordinateur.
